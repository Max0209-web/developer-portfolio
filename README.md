# Максим — сайты, Telegram-боты и автоматизация

Личная витрина работ: можно открыть проекты, посмотреть интерактивные демонстрации и перейти к исходникам.

## Что посмотреть

- CryptoNews Publisher — бот-редактор новостного канала. Демонстрационная главная панель получена из функций приложения.
- CEX/DEX Monitor — рыночные интеграции и Telegram-панель. Нулевое тестовое состояние, без реальных сделок.
- FORM Studio — авторский демонстрационный сайт-визитка вымышленного архитектурного бюро.
- AI Life Assistant — ссылка на Telegram SaaS-проект с напоминаниями и подписками.

## Запустить

```bash
python -m http.server 8765
```

Открыть `http://127.0.0.1:8765/`. Для ботов нужен HTTP-сервер, поскольку демонстрации читают JSON-файлы. Сборка и npm не требуются.

Фильтры работ, переходы по сценариям и пример брифа на сайте FORM работают локально. Бриф не отправляет данные. Демо ботов не вызывает внешние API.

## Визуальный стиль

Личная подача, тёмная палитра, мятные и лиловые акценты, оригинальные аниме-персонажи, которые показывают на важные блоки. Картинки — часть оформления портфолио, не скриншоты Telegram.

`media/` — кадры и короткий демонстрационный ролик, снятые с этой версии сайта. `data/` — офлайн-состояния панелей. Исходники работы с биржами и новостями хранятся в отдельных репозиториях.

## Интерактивные сайты

- [ORBIT](concepts/orbit.html) — Атлас вымышленных миров. Выбираешь пункт назначения, а карта меняет траекторию и показывает детали перелёта.
- [MOKO](concepts/moko.html) — Меню под настроение. Выбираешь вкус и объём, видишь цену и собираешь пробный заказ.
- [NOISE ROOM](concepts/noise.html) — Бочка, малый и хэт. Расставляешь удары, меняешь темп и сразу слышишь результат.
